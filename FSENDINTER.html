Before you start

  1. Connect both devices to the internet. They can be on different networks. If a direct link fails, use the same Wi-Fi or a phone hotspot.
  2. Open this page on both devices.
  3. On the sending device, tap Send and choose a folder or files. A QR code appears.
  4. Scan it with the other device's camera, or type the code, then tap Download.

Files go straight from device to device (or through an encrypted relay if needed), never stored on a server. Keep this page open until it finishes.
